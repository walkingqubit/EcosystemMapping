# Mainframe Modernization Ecosystem Map

An interactive 3D visualization of a mainframe modernization 
ecosystem across multiple cloud environments (AWS, Azure, GCP, Private).

## 🚀 Live Demo
[View the visualization](https://walkingqubit.github.io/EcosystemMapping/)

## Features
- 60+ nodes across 6 entity types (mainframes, apps, microservices, 
  cloud services, gateways, teams)
- Animated dependency edges
- Type filtering, search & fly-to navigation
- What-if decommission impact analysis

## How to Run
Open `index.html` in any modern browser — no server or build step required.

## Controls
- **Left-drag**: Rotate | **Right-drag**: Pan | **Scroll**: Zoom
- Hover for tooltips, click nodes for details
